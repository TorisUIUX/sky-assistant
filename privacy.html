Sky - Privacy Policy

Last updated: 10 November 2026

Sky is a personal, self-hosted voice assistant that is used only by its developer (David) on his own home server. It is not offered to the public. This policy explains how the app handles Google user data.

Data accessed

With the developer's explicit consent, the app requests read-only access (OAuth scopes) to the developer's own Google account: Gmail (read-only), Google Calendar (read-only) and Google Tasks (read-only), plus basic profile information (email address).

How the data is used

Data is read only when the developer asks a question (for example, "what is on my calendar tomorrow?") and is used solely to produce the answer. Retrieved content is passed to an AI language model (Google Gemini API) in order to generate a short spoken summary. It is not used for advertising, is not sold, is not shared with any other third party, and is not published.

Storage

The OAuth access credentials are stored on the developer's private home server with restricted file permissions. Retrieved emails, events and tasks are not stored permanently by the app.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access and deletion

The developer can revoke the app's access at any time at myaccount.google.com/permissions and delete the stored credentials from the server.

Changes

This policy may be updated; the date above shows the latest revision.
